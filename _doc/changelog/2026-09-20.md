# 2026-09-20

From TopArrow 0.3.6 onward the platform includes embeddable CPython 3.13, and this template allows Python.

## What changed

- `AGENTS.md`: Python is in the runtime list. The health-check and port rules cover PHP, Node, and Python. Java is still unsupported.
- `_doc/aicode/rules/runtime.md`: the choice table includes Python; local lookup includes `runtime\python\python.exe`; vendor is documented, and `.venv`, a bundled interpreter, and a platform pip are ruled out.
- `_doc/projectinfo/overview.md` and `_doc/plan/README.md`: the runtime list and lookup notes match.

## For later work

For Python, set `runtime.type` in `manifest.json` to `python` and `entry.main` to the entry `.py` file. Install third-party libraries with `pip install --target vendor` and unpack them into the app. Do not install them on the user's machine at run time.
