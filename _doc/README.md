# _doc

Project notes live in this directory. The maintenance rules are in `AGENTS.md` at the repository root.

| Directory | Role |
| --- | --- |
| `changelog/` | Change log. Update `SUMMARY.md` on every change. |
| `projectinfo/` | This app's directories, modules, and stack. |
| `plan/` | Implementation plans for larger features. |
| `testcase/` | Test plans and cases. |
| `references/` | External APIs and third-party docs. |
| `writing/` | Design notes, evolution records, and similar writing. |
| `aicode/rules/` | Runtime choice and how to find runtimes on this machine: `runtime.md`. Pre-publish check: `publish_check.md`. Project-specific rules can go here too. |
| `aicode/examples/` | Reference implementations for this app (optional). |
